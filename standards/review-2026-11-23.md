# Standards drift reviewed for the v0.28.2 GHASH candidate

**Disposition: reviewed standards pins refreshed; no GHASH implementation change.**
The 13 authority observations are real. None lists v0.28.2 among its affected
milestones. This review is not a freshness receipt, acceptance of new authority
pins by itself, or approval to implement newly registered protocols.

## IANA: six changed collections

The official XML was compared with the committed snapshots. A second HTTPS
fetch used addresses obtained from Google DNS-over-HTTPS, with hostname and
certificate validation. It reproduced the six observed digests and the two
unchanged pins (TLS ECH configuration extensions and certificate transparency).

| Collection | Change that matters for downstream review |
| --- | --- |
| [DNS parameters](https://www.iana.org/assignments/dns-parameters/dns-parameters.xml) | New underscored names: TXT `_trooth-key`; TLSA `_client` and `_device`. These are DNS registrations, not changes to GHASH. |
| [HPKE](https://www.iana.org/assignments/hpke/hpke.xml) | Revised registry references, clarification of the Auth column, a two-stage KDF field, and zero lengths for the export-only AEAD. Preserve the distinction between registry metadata and the project's admitted HPKE specification. |
| [QUIC](https://www.iana.org/assignments/quic/quic.xml) | Multipath registrations now reference RFC 10069 rather than the draft. This does not add multipath to the TLS adapter. |
| [SMI numbers](https://www.iana.org/assignments/smi-numbers/smi-numbers.xml) | Adds OCSP module identifier 130 and revises references for existing composite signature, voucher, trust-anchor and OCSP registrations. Preserve PKIX/namespace ownership. |
| [TLS extensions](https://www.iana.org/assignments/tls-extensiontype-values/tls-extensiontype-values.xml) | Adds `dane_clientid` (63), temporary `trust_anchors` (51764) and an AmbesaSQL ALPN entry; updates the EPP-over-QUIC reference. Registration is not implementation or admission. |
| [TLS parameters](https://www.iana.org/assignments/tls-parameters/tls-parameters.xml) | New BELT/BASH cipher suites, BIGN curves and signatures, and the MLKEM1024X448 group; also a contact update. Do not enable these allocations through a metadata refresh. |
